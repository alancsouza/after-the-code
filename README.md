# After the Code

Blog pessoal de Alan Souza, publicado com GitHub Pages e Jekyll.

## Como publicar um novo texto

1. Crie um arquivo em `_posts/` com o nome no formato `AAAA-MM-DD-titulo-do-texto.md`.
2. Comece o arquivo com o cabeçalho abaixo e escreva o texto em Markdown logo depois:

```
---
layout: post
title: "Título do texto"
date: 2026-11-15 12:00:00 -0300
resumo: "Uma frase curta que aparece na página inicial."
---
```

3. Faça o commit na branch `main`. O GitHub Pages atualiza o site em alguns minutos.
